##  Core Timer Features

* **Zero-Drift Background Engine:** Powered by a wall-clock timestamp engine and background worker, the timer never freezes or loses time—even if you switch tabs, minimize the browser, or accidentally close the page.

##  24/7 Live Focus Radio -->  How It Works

Instead of loading heavy video players that consume high RAM, **TIMER** includes a dedicated **24/7 Live Internet Radio Deck** that streams pure audio directly in the background.

### 1. Instant Study Stations

Click any of the preloaded station chips (**Lofi Chillhop**, **Nightwave**, **Study Groove**, **Deep Drone**, **Space Ambient**, or **Synphaera**) to start streaming continuous, ad-free focus music immediately.

### 2. Search Thousands of Live Stations Inside the App

Want a different style of music? Use the built-in search bar right below the station buttons:

1. Type any keyword such as `lofi`, `piano`, `ambient`, `classical`, or `chill` into the input box.

2. Click ** Find / Play** to fetch live working stations from the global radio directory.

3. Click ** Play** next to any result to listen immediately.

### 3. Paste Any Direct Stream Link (`.mp3` / `.aac`)

If you have a direct radio stream link from directories like [FMStream.org](http://fmstream.org) or [SomaFM](https://somafm.com), simply paste the `https://...` stream URL into the same search box and click **Find / Play**.


##  Offline Sounds & Local Audio Bar

* **15 Offline Cognitive Sounds:** Select from 15 built-in procedural sounds—including *14Hz SMR Neuro-Stillness*, *18Hz Beta Pulse*, *Speech-Blocker Vocal Mask*, *Brown/Pink/White Noise*, and *Binaural Beats*—that run 100% offline with zero data usage.

* **Native Chrome Audio Player (For Converted YouTube / Local MP3s):** Load your own downloaded or converted YouTube study tracks (`.mp3`, `.m4a`, `.wav`) into the clean white Chrome progress bar with full timeline scrubbing, speed control, and playlist looping.
